## 5 · Lecture: *Symbology*, Making Attributes Visible *(15 min)*

- Symbology is *analysis*, not decoration: the same data with different symbols can tell different stories.

\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_

- The main methods: *Single Symbol*; *Categorized* / *Unique Values* (qualitative, e.g., species, ownership); *Graduated* (quantitative, e.g., age, basal area) and how class breaks change the message.

\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_

\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_

- Choosing well: color for categories vs. sequences; how many classes; why raw counts can mislead (normalize instead).

\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_

**Key terms:** *Symbology* · *Categorized* · *Graduated* · *Unique Values* · class breaks
